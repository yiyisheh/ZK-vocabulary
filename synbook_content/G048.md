与“离开与返回”相关的单词，分别是 **leave** (76) 和 **return** (123)。

这两个单词表示空间移动或物品传递上完全相反的动作，它们的主要区别在于**动作的方向**以及**语境的侧重点**：

### 1. 动词的区别：leave 与 return

* **leave（离开 / 留下 / 遗忘）：** 侧重于从某个地方离去。它还有一个非常常见的用法，表示把某物或某人“留在”某个地方，或者不小心“遗忘”在某处。
* *例句：“She **left** home early this morning to catch the bus.”（她今天一大早就出门去赶公交车了。）*

* **return（返回 / 归还）：** 侧重于回到原来的地方（相当于 go back / come back），或者把借来的东西还给原主（相当于 give back）。
* *例句：“Please **return** the book to the library on time.”（请按时把书还给图书馆。）*

---

### 2. 固定搭配的区别：

* **leave** 常搭配：leave for (动身前往某地) / leave sth. at + 地点 (把某物落在某地)
* **return** 常搭配：return to + 地点 (返回某地) / return sth. to sb. (把某物还给某人)

**总结一下：**
如果是表达“离开”某个地方或把东西“落”在某处，用 **leave**；如果是自己“回来”原处，或者把借来的东西“归还”，用 **return**。
